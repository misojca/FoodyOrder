# Food Order Platform  
### Mobile Client & Admin Console

## Overview
This repository contains the mobile client application for food ordering and delivery management system.

The system comprises:
- A feature-rich mobile app for customers (Kotlin / Android)
- A minimal Admin Console (JavaScript / Node.js) for managing orders in real time

The project demonstrates proficiency in modern mobile development, Firebase integration, clean architectural design, and real-time data handling.

---

## Key Features

### Mobile Client
- **User Authentication** – Secure sign-up and login using email/password
- **Restaurant Search** – Real-time search and filtering by cuisine or name
- **Shopping Cart** – Persistent cart with quantity updates before ordering

### Admin Console (Order Management)
- **Order Dashboard** – View all incoming orders
- **Status Management** – Update order status manually
- **Real-time Synchronization** – Instant updates reflected in the mobile app

---

## Technology Stack

### Mobile Client (Android)
- **Language:** Kotlin
- **Platform:** Android
- **Backend:** Google Firebase
  - Firebase Authentication
  - Firebase Firestore (real-time NoSQL database)
- **UI/UX:** Material Design Components

### Admin Console
- **Language:** JavaScript (Node.js)
- **Interface:** Command-line
